# Instructions for agents

Working rules (branch + pull request, never commit to `main`, commit messages in English, the
only allowed trailer is `Co-Authored-By`) and the security invariants are in
[`CLAUDE.md`](CLAUDE.md). They apply to every agent session started by a maintainer, whatever
the tool. An external contributor — human or agent — follows
[`CONTRIBUTING.md`](CONTRIBUTING.md), DCO included.
